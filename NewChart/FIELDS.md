# FIELDS — new-chart

## Поля данных

| Alias в JS | Колонка SQL | Тип | Описание |
|---|---|---|---|
| total | emp_cnt_total | BigInt | Уникальные сотрудники встречи |
| management | emp_cnt_management | BigInt | Сотрудники управленческой структуры |
| functional | emp_cnt_functional | BigInt | Сотрудники функциональной структуры |

## Ручные настройки Proteus

- [x] Добавить все поля из таблицы выше в **«Измерения»**
- [x] Порядок полей в `CFG.fields` совпадает с порядком в SQL
- [ ] Лимит строк / пагинация — не требуется (одна агрегатная строка)
- [ ] Сортировка по умолчанию — не требуется

## Статические значения (зафиксированы в JS)

| Поле | Значение | Причина |
|---|---|---|
| snapshot_dt | 2026-07-01 | Дата среза (нет в SQL) |
| segment_nm | Четверговая Оффлайн | Название сегмента (нет в SQL) |
| struct_color.management | #f2a8b8 | Цвет для управленческой структуры |
| struct_color.functional | #c9a2ee | Цвет для функциональной структуры |
| rule_txt | (см. CFG.text.rule) | Правило формирования встречи |

## Примечания

SQL отдаёт **одну агрегатную строку** с тремя колонками. `buildModel()` делает unpivot: одна строка → две записи (management + functional).
