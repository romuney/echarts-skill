# PATTERNS — RETRO и рецепты

Единственный реестр известных падений. Каждое — реальный баг из практики.
Читай ПЕРЕД кодом.

## RETRO

| # | Симптом | Причина | Лечение |
|---|---|---|---|
| 1 | Виджет пустой, ошибок нет | overlay не создан: функция монтажа описана, но не вызвана | в БЛОКЕ 6 монтаж — самовызываемая IIFE; `render()` пишет в `overlay` из замыкания |
| 2 | График исчезает при ресайзе/фильтре | Proteus перезапускает скрипт, локальное состояние теряется | состояние только в `window.__pvtState[CFG.ns]` |
| 3 | График мигает / бесконечный цикл | `ResizeObserver` вызывает `render()`, тот меняет размеры | в observer только правка габаритов overlay, без `render()` |
| 4 | Два графика друг на друге | старый overlay не удалён перед вставкой | `host.querySelector('.<ns>-overlay')` → `removeChild` |
| 5 | Ломается весь дашборд Proteus | глобальные CSS-селекторы утекли за overlay | каждый селектор в `buildCSS()` начинается с `.<ns>-` |
| 6 | Интерфейс без стилей, «куча текста» | в разметке есть классы, а CSS макета не перенесён | каждый класс из `buildHTML()` имеет правило в `buildCSS()` |
| 7 | Тултип обрезан или без стилей | тултип внутри overlay с `overflow`, либо в `body`, куда не достаёт `<style>` overlay | тултип в `body`, `position:fixed`, стили ДУБЛИРОВАТЬ инлайн |
| 8 | Элемент не прячется | ставится атрибут `hidden` или только класс | `style.display='none'` или `style.opacity='0'` |
| 10 | Дата — число вида `1735689600000` | `DATE`/`DATETIME` из Proteus приходит epoch, а не строкой из UI | все даты через `toDate()` из БЛОКА 2 |
| 11 | В графике только одна строка | чтение `data[0]` вместо всего массива | `rawData = data`, дальше `forEach` |
| 12 | Неожиданные цифры в виджете | значения захардкожены в `CFG` вместо чтения из SQL | нет поля — СПРОСИ, согласованные статики в `FIELDS.md` |
| 13 | `SyntaxError` при вставке в Proteus | backticks / template-literals / стрелочные / `let`-`const` | только `var`, `function`, конкатенация строк |
| 14 | `option is not defined` / график не рендерится | `option` внутри функции/IIFE или не в конце файла | `option = {...}` глобально, последний блок |
| 15 | Нашёлся чужой узел / null | `document.getElementById` видит весь дашборд | только `overlay.querySelector('.<ns>-...')` |
| 16 | Ошибка не видна, виджет пуст | молчаливый `catch` | в `catch` пиши `option.graphic` с текстом ошибки |
| 17 | Поле есть в SQL, но `undefined` в JS | поле не добавлено в «Измерения» или имя не совпало | сверь SQL == `CFG.fields` == «Измерения» побуквенно |
| 18 | Порядок строк случайный | JS полагается на `ORDER BY`, а серверная пагинация его перебила | явный `sort` в `buildModel()` |
| 19 | Тултип не появляется вообще | узел тултипа лежит в `buildHTML()` или создаётся внутри `render()`: `innerHTML` убивает его каждый раз | создать ОДИН раз в `body` до `render()`, кэшировать в переменную |
| 20 | Тултип моргает / исчезает при наведении | hover вызывает полный `render()`, он пересобирает DOM под курсором | hover трогает только `renderTip()`; полный `render()` — только на клик |
| 21 | Шрифт в тултипе отличается от графика | тултип в `body`, а `font-family` задан только на `.<ns>-root` — наследования нет | единый `CFG.fonts.family`, повторён В ПРАВИЛЕ тултипа явно |
| 22 | Агент засыпает вопросами про дату и `id` | требование «поле-период» применено к графику-снимку, где оси времени нет | `CFG.mode='snapshot'`; про дату, `id` и стили НЕ спрашивать |

## Рецепт: перенос CSS макета

Кладётся в `buildCSS()` массивом строк с `join('')`. Первый элемент `'<style>'`,
последний `'</style>'`. Переменная `P = '.' + CFG.ns` подставляется в каждый селектор.
Значения берутся из `CFG.colors/fonts/spacing`, а не пишутся числами в строке.
Цвета удобно держать как `[R,G,B,A]` и гонять через `cssColor()`.

Динамические значения (ширина бара, цвет ячейки по шкале) остаются инлайн
в `style="..."` — их нельзя выразить статичным правилом.

## Рецепт: перерисовка и интерактив

`render()` полностью пересобирает `overlay.innerHTML`, потом заново вешает все обработчики.
Клик по переключалке: меняет `state`, вызывает `render()`. Никакого ручного
патча отдельных узлов параллельно с полным рендером — один источник правды.

Для частых событий (`mousemove` по ячейкам) не вызывай `render()`: меняй только
стиль/текст тултипа и классы подсветки.

## Рецепт: большие объёмы

Если строк десятки тысяч — лимит Proteus обрежет выборку молча. Заведи в SQL
отдельное поле с честным итогом до лимита и покажи в интерфейсе «Показано X из Y».
Саму выборку можно упаковать в SQL в компактную строку и распаковать в `buildModel()`;
выбранный способ и его точность зафиксируй в `FIELDS.md`.

## Рецепт: скролл и габариты

Overlay всегда `position:absolute` с `width/height:100%` и `overflow:auto`.
Внутри разделяй фиксированную шапку и скроллируемое тело через flex-колонку,
иначе на маленьком виджете управление уезжает за пределы.


## Рецепт: тултип, который реально работает

Три условия, все обязательные:

1. **Живёт в `body`, создаётся один раз.** Узел создаётся в `mount()` ДО первого
   `render()` и кэшируется. В `buildHTML()` его НЕТ — иначе `innerHTML` убьёт узел.
2. **`position:fixed` и свой `font-family`.** Тултип вне `.<ns>-root`, поэтому не
   наследует ни шрифт, ни цвет. Координаты — от `getBoundingClientRect()` цели.
3. **hover не вызывает полный `render()`.** Для hover — лёгкий `renderTip()`, который
   меняет только содержимое и позицию тултипа. Полный `render()` — только на клик.

Слушатели делегируются от `overlay` через `data-*` атрибуты, а не вешаются на каждый узел.

## Рецепт: единый шрифт

Стек задаётся ОДИН раз в `CFG.fonts.family` и подставляется в ДВА места:
в `.<ns>-root` и в правило `.<ns>-tip`. Внутри корня добавь `font-family:inherit`
для `*`: `button` и `input` НЕ наследуют шрифт по умолчанию и берут системный.
Никаких локальных `font-family` в отдельных правилах быть не должно.

## RETRO 9. Обработчики и render

Делегирование от overlay и привязка РОВНО ОДИН РАЗ снаружи `render()`. Узел overlay
при `innerHTML` не пересоздаётся, поэтому слушатели переживают перерисовку.
Привязка внутри `render()` даёт N обработчиков после N кликов. Симптомы:
тултип мигает, выделение снимается сразу после клика, Escape срабатывает многократно.

## RETRO 23. Точка в префиксе разметки

`var P = '.' + CFG.ns` допустим ТОЛЬКО в `buildCSS()`. Тот же код в `buildHTML()` даёт
`class=".pvt-root"`: стили не применяются, `overlay.querySelector('.pvt-root')` возвращает
null, интерактив мёртв. Симптом: нестилизованный текст столбиком.

## RETRO 24. Молчаливый catch

Из `catch` БЛОКА 6 нельзя обращаться к `option`: присваивание в БЛОКЕ 7 ещё не
выполнено, `typeof option === 'undefined'`, ветка не срабатывает никогда. Ошибку
выводить текстом в overlay. Симптом: пустой белый блок без ошибок в консоли.

## RETRO 25. Невызванный render

Объявить `render()` недостаточно — нужен ровно один вызов в теле `mount()`.
Иначе canvas уже скрыт, overlay пуст, консоль чистая. Симптом: белое пятно.

## RETRO 26. Fixed-тултип и координаты

Тултип в body с `position:fixed` ждёт координаты вьюпорта. Вычитание rect корня
или клампинг по `clientWidth` контейнера уводит его за пределы виджета.
