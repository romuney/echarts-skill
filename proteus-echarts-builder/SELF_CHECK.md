# SELF_CHECK — обязательная проверка перед сдачей

Для каждого пункта укажи `PASS`, `FAIL` или `N/A` и доказательство `файл:строка`.
`FAIL` → исправь → повтори проверку. Без полного PASS работа не сдана.

`N/A` допустим ТОЛЬКО в условных секциях (Q, I) и требует одной строки пояснения,
почему функции нет в задаче. `N/A` в обязательных секциях = `FAIL`.

Номера в скобках — ссылки на RETRO в `PATTERNS.md` (1–26) и `TABLES.md` (27–40).
Пункты `(auto)` закрываются выводом `validate.py` — копируй его вердикт, не проверяй
глазами. Остальные — только твоя ответственность.

**Что проходить:**

| Секция | Где лежит | Когда |
|---|---|---|
| A, P, M, S, C, D, F, Z | здесь | всегда |
| Q1–Q8. SQL | `SQL.md`, раздел 5 | только если правил `<name>.data.sql` |
| I1–I16. Интерактив | `TABLES.md`, раздел 6 | только если читал `TABLES.md` |

В РЕЖИМЕ B (точечная правка) проходи A, Z, затронутые пункты и — обязательно —
секцию «Связка» из `REGRESSION.md`.
