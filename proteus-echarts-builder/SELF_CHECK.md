# SELF_CHECK — обязательная проверка

Пройди ВСЕ пункты перед сдачей. Для каждого укажи `PASS` или `FAIL` и доказательство
`файл:строка`. `FAIL` → исправь → повтори проверку. Без полного PASS работа не сдана.

Номера в скобках — ссылки на RETRO в `PATTERNS.md`.

## A. Машинная проверка (делается ПЕРВОЙ)

- [ ] A1. Запущен `python3 validate.py <путь>.chart.js`, вывод вставлен в ответ дословно.
- [ ] A2. В выводе `0 FAIL`. Любой FAIL → исправить и перезапустить.
- [ ] A3. Каждый WARN либо устранён, либо объяснён одной строкой.

Пункты ниже, помеченные (auto), закрываются выводом скрипта — копируй его вердикт,
не проверяй глазами. Остальные — только твоя ответственность.

## S. Стоп-баги

- [ ] S1. `option` присваивается глобально, вне функций и IIFE, в БЛОКЕ 7 и в самом
      конце файла (RETRO 14).

- [ ] S3. Монтаж — самовызываемая IIFE; overlay реально создаётся, а не остаётся
      `null` в невызванной функции (RETRO 1).
- [ ] S4. Вся разметка пишется только в переменную overlay из замыкания `mount()`.
- [ ] S5. В `buildCSS()` КАЖДЫЙ селектор начинается с `.<ns>-`; голых `div`, `table`,
      `th`, `button`, `*` без префикса нет (RETRO 5).
- [ ] S6. Каждый CSS-класс из `buildHTML()` имеет правило в `buildCSS()`: стили макета
      перенесены, а не выброшены (RETRO 6).
- [ ] S7. Тултип в `body` с `position:fixed`, его стили дублированы инлайн (RETRO 7).
- [ ] S8. Скрытие элементов через `style.display`/`style.opacity`, а не `hidden` или
      одного `classList` (RETRO 8).
- [ ] S9. Обработчики навешиваются ОДИН РАЗ СНАРУЖИ `render()`, делегированием
      от overlay. Внутри тела `render()` нет ни одного `addEventListener` (RETRO 9). (auto)
- [ ] S10. Даты гонятся через `toDate()`: epoch-ms, epoch-s, `YYYY-MM`, `YYYY-MM-DD` (RETRO 10).
- [ ] S11. Нет backticks, template-literals, стрелочных функций, `let`/`const` (RETRO 13).
- [ ] S12. Нет `document.getElementById`; поиск только `overlay.querySelector` (RETRO 15).
- [ ] S13. Корень без собственной карточки: нет двойного фона, рамки, тени, padding.
- [ ] S14. В теле `mount()` есть вызов `render();` вне определения функции: без него
      overlay остаётся пустым, canvas уже скрыт, ошибок в консоли нет (RETRO 25). (auto)
- [ ] S15. В `buildHTML()` префикс БЕЗ точки (`var P = CFG.ns`); точка только в
      `buildCSS()`. В разметке нет `class="."` (RETRO 23). (auto)
- [ ] S16. Позиция fixed-тултипа считается от `getBoundingClientRect()` без вычитания
      rect корня; клампинг по `window.innerWidth/innerHeight` (RETRO 26). (auto)
- [ ] S17. Нет `document.addEventListener` и `window.addEventListener` внутри `render()`. (auto)
