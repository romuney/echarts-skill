# REGRESSION — сценарный чек-лист интерактивных таблиц

`SELF_CHECK.md` отвечает на вопрос «код соответствует контракту?».
Этот файл отвечает на другой: **«мы не сломали то, что уже работало?»**

Когда проходить:

- **РЕЖИМ A** (новая таблица) — целиком, перед сдачей.
- **РЕЖИМ B** (точечная правка) — только затронутые секции ПЛЮС обязательный
  сквозной блок «Связка» внизу. Он дешёвый и ловит большинство регрессий.

Читай этот файл только если читал `TABLES.md`. Для обычного графика он неприменим.

Отмечай `+` пройдено, `-` сломано, `n/a` неприменимо. `n/a` требует одной строки
пояснения — почему функции нет в макете.

## Объём данных

- [ ] 0 строк — виден `CFG.text.noData`, ошибок нет
- [ ] 1 строка
- [ ] `pageSize - 1` строк
- [ ] ровно `pageSize` строк
- [ ] `pageSize + 1` строк — появилась вторая страница
- [ ] 1000+ строк — интерфейс отзывчив, в DOM только текущая страница

## Поиск

- [ ] совпадение на первой странице
- [ ] совпадение на дальней странице — находится, страница пересчитана
- [ ] нет совпадений — корректный empty-state, а не пустая таблица без объяснения
- [ ] спецсимволы (`<`, `&`, `"`, `%`) — вёрстка не разъехалась
- [ ] подсветка совпадения не ломает HTML соседних ячеек

## Сортировка

- [ ] ASC
- [ ] DESC
- [ ] `null` / пустые / `NaN` — внизу И при ASC, И при DESC
- [ ] сортировка после поиска — сортируется найденное, а не всё
- [ ] сортировка после перестановки колонок

## Пагинация

- [ ] first / previous / next / last
- [ ] страница пересчитывается после смены поиска, фильтра или сортировки
- [ ] на последней странице неполный набор строк отрисован корректно

## Копирование и экспорт

- [ ] без поиска — попадают ВСЕ строки, а не текущая страница
- [ ] с поиском — все найденные строки
- [ ] соблюдён текущий порядок колонок
- [ ] скрытые и невыбранные колонки исключены
- [ ] вставка в Excel даёт корректные колонки и строки

## Колонки

- [ ] выбор метрик
- [ ] сворачивание группы — выравнивание потомков не поехало
- [ ] перестановка колонок — шапка, строки и экспорт совпадают
- [ ] `locked`-поля (дата, единица) нельзя снять
- [ ] выбраны только `locked`-поля — показан empty-state для метрик

## Тултип

- [ ] в центре виджета
- [ ] у правого края — не уезжает за вьюпорт
- [ ] у левого края
- [ ] у нижнего края
- [ ] hover не вызывает полный `render()`

## Скролл

- [ ] вертикальный
- [ ] горизонтальный
- [ ] sticky-блок держится при обоих направлениях одновременно

## Связка (проходить ВСЕГДА, даже на однострочной правке)

- [ ] поиск → сортировка → пагинация → копирование, подряд, в одном сеансе
- [ ] после этой цепочки цифры в таблице совпадают с цифрами до неё
